# 커버 이미지

파일만 넣으면 카드와 상세 페이지의 커버가 바뀝니다. 코드 수정은 필요 없습니다.
이미지가 없으면 제목으로 만든 타이포그래피 커버가 표시됩니다.

| 대상 | 경로 | 예 |
| --- | --- | --- |
| 프로젝트 | `projects/<프로젝트 파일명>.<확장자>` | `projects/gajigaji04-github-io.png` |
| 블로그 글 | `blog/<글 slug>.<확장자>` | `blog/post-test.jpg` |

- 확장자: png, jpg, jpeg, webp, avif
- 권장 크기: **1200 × 630** (비율이 다르면 가운데 기준으로 잘립니다)
- 빌드 시 여러 크기의 webp 로 자동 최적화됩니다.

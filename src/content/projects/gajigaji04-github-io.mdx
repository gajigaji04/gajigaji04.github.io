## 개요

기존 Jekyll 테마(Plainwhite) 기반 블로그를 개발자 개인 홈페이지로 개편했습니다. 프로필, 프로젝트, 블로그를 하나의 일관된 디자인 언어로 묶는 것이 목표입니다.

## 문제 정의와 목표

- [x] 백엔드 없이 정적 배포 유지 (GitHub Pages)
- [x] 다크/라이트 테마와 코드 하이라이팅을 함께 지원
- [x] 프로젝트 필터 · 보기 전환, 블로그 전문 검색
- [x] 기존 URL과 SEO 자산 보존

## 주요 기능

- **프로필 · 프로젝트 · 블로그**를 하나의 미니멀 디자인으로 통일
- **다크/라이트 테마** — OS 설정을 따르고, 선택은 기억되며 첫 화면 깜빡임 없음
- **전문 검색**(⌘K) — 서버 없이 Pagefind 정적 인덱스로 글 · 프로젝트 검색
- **프로젝트 필터 · 보기 전환**, 블로그 **검색 · 카테고리 · 태그** 필터 (URL 에 상태 유지)
- **GitHub 활동 그래프** — 빌드 시 GitHub API 로 갱신, 매일 자동 재빌드
- **기존 Jekyll URL 리다이렉트**, RSS, sitemap

## Overview

**THE ARCANA · 더 아르카나** — 오래된 유럽 점집 분위기를 담은 반응형 타로 점술 웹서비스입니다.
점술 주제, 카드 수, 해석 여부, 질문을 한 화면에서 정한 뒤 카드를 직접 고르면 결과와 해석을 보여 줍니다. 한국어 · 일본어 · 중국어 · 영어를 지원합니다.

## 주요 기능

- **점술 진행** — 설정 → 카드 선택 → 결과 3단계. 카드 1 / 3 / 5 / 10장, 3장일 때는 배치(과거 · 현재 · 미래 / 상황 · 선택A · 선택B) 선택
- **점술 주제 10가지** — 종합, 커리어, 취업, 학업, 금전, 연애, 인간관계, 건강, 사업, 연간 운세
- **카드 도감** — 78장(메이저 22 + 마이너 56) 목록과 카드별 의미 페이지
- **카드만 보기 / 해석 보기** 모드, 결과 카드를 순서대로 공개(동작 줄이기 설정 시 한 번에 공개)

## Technical Details

- **카드 선택**: Fisher-Yates 셔플로 78장을 섞어 33장의 선택 풀을 만들고, 카드를 고르는 순간 정/역방향을 정합니다.
- **해석 생성**: `InterpretationProvider` 인터페이스 뒤에 규칙 기반 구현을 두었습니다. 메이저 카드 비율, 역방향 비율, 첫 카드 → 마지막 카드 흐름 같은 조건으로 종합 해석 문단을 조합합니다. 이후 LLM 기반 구현으로 교체할 수 있도록 분리한 구조이며, LLM 연동 자체는 구현되어 있지 않습니다.
- **다국어 2계층**: UI 문자열은 react-i18next, 카드 · 주제 같은 도메인 데이터는 `Record<Lang, T>` 형태로 한국어 원본에 언어별 번역을 병합합니다. 번역이 없으면 현재 언어 → 영어 → 한국어 순으로 대체합니다.
- **카드 그림**: 이미지 파일 없이 SVG 로 직접 그리며, 별 모양 꼭짓점 · 원 위 좌표를 계산하는 기하 함수를 사용합니다.

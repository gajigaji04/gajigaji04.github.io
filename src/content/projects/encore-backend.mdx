## Overview

많은 사용자가 동시에 몰리는 **콘서트 티켓팅** 상황을 다루는 백엔드를 목표로 시작한 프로젝트입니다.
2026년 11월 기준으로 프로젝트 골격만 만든 **초기 세팅 단계**이며, 도메인 기능은 아직 구현되지 않았습니다.

## 주요 기능

아직 구현된 기능이 없습니다. 기능이 추가되면 이 페이지를 갱신합니다.

## Technical Details

현재 저장소에서 확인할 수 있는 개발 환경입니다.

- Java 21 toolchain, Spring Boot 4.1, Gradle 9
- 의존성: Spring Web MVC, Spring Data JPA, Validation, Actuator, Lombok, PostgreSQL 드라이버
- 테스트: JUnit Platform(애플리케이션 컨텍스트 로드 테스트)

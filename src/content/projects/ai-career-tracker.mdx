## Overview

**CareerHub** — 개발자 취업 준비 과정에서 흩어지는 학습 기록, 프로젝트, 지원 현황, 이력서를 한곳에서 관리하는 플랫폼입니다.
쌓인 기록을 AI 에 컨텍스트로 넘겨 **지원 건별 자기소개서 초안과 예상 면접 질문**을 생성합니다. 기획부터 백엔드 · 프론트엔드 · 클라우드 배포까지 혼자 진행했습니다.

## 주요 기능

- **기록 관리** — 학습(Study), 프로젝트, 지원 현황(Application), 이력서 CRUD
- **AI 분석** — 지원 건 + 최근 프로젝트 5개 + 학습 기록 5개로 프롬프트를 구성해 자기소개서 초안 · 예상 면접 질문 생성, 결과는 덮어쓰지 않고 누적 저장
- **이력서 버전 관리** — S3 업로드, 버전 자동 증가, presigned URL 로 다운로드
- **인증** — 회원가입 · 로그인, 비밀번호 재설정 메일, SMS 아이디 찾기
- **대시보드** — 지원 현황과 기록 통계 시각화

## Technical Details

- **토큰 무효화** — Access 1시간 / Refresh 30일. 사용자별 `tokenVersion` 을 두어 로그아웃 · 비밀번호 재설정 시 기존 Refresh 토큰을 한 번에 무효화합니다.
- **비밀번호 재설정** — `crypto.randomBytes` 로 만든 1회용 만료 토큰.
- **요청 제한** — 인증 API 15분 10회, AI API 1시간 20회(express-rate-limit).
- **외부 서비스 대체 경로** — SMS(Solapi) 자격 증명이 없으면 로그로 대체해 개발 환경에서도 흐름을 확인할 수 있게 했습니다.
- **AI** — Groq SDK(`llama-3.3-70b-versatile`)를 서비스 계층에서 호출합니다.
- **입력 검증 · 문서화** — Zod 스키마 검증, Swagger(swagger-jsdoc) API 문서, pino 로깅, helmet.
- **테스트** — 백엔드 Vitest + Supertest(서비스 6개 + 통합 테스트), 프론트엔드 Vitest 테스트 3개.

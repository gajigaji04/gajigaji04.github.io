## Overview

여러 프로젝트의 Git 활동과 API 서버 상태를 따로 확인해야 하는 불편을 줄이기 위해, 이를 하나의 대시보드로 모으는 개발자 도구를 목표로 시작했습니다.
2026년 11월 기준으로 백엔드 · 프론트엔드 프로젝트 골격과 README 초안만 작성한 **초기 세팅 단계**입니다.

## 주요 기능

아직 구현된 기능이 없습니다. README 에 정리한 계획은 다음과 같습니다.

- 프로젝트 관리
- Git 활동 모니터링
- API 상태 모니터링
- 통합 대시보드

## Technical Details

현재 저장소에서 확인할 수 있는 개발 환경입니다.

- 백엔드: Node.js · Express 5, nodemon
- 프론트엔드: React 19, TypeScript, Vite

## Architecture

`backend/`(Express)와 `frontend/`(React + Vite)로 나눈 구조이며, 세부 설계는 아직 확정되지 않았습니다.

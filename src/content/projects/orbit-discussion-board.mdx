## Overview

React 클라이언트와 Express REST API, MySQL 로 구성한 커뮤니티형 게시판입니다.
2023년 11–12월에 처음 개발했고, 2026년 10월에 MySQL 연결 · 디자인 · 문서를 다시 정비했습니다.

## 주요 기능

- **게시글** — 작성 · 조회 · 수정 · 삭제
- **댓글** — 작성 · 조회 · 삭제
- **회원** — 가입 · 조회 · 수정 · 삭제, bcrypt 비밀번호 해싱
- **페이지** — 홈, 게시글 목록 · 상세, 소개, 문의

## Technical Details

- **공통 에러 처리** — 잘못된 JSON 은 400, 중복 키(`ER_DUP_ENTRY`)는 409 로 응답하는 공통 에러 핸들러와 `asyncHandler` 래퍼
- **DB 초기화** — 서버 시작 시 데이터베이스와 테이블을 자동 생성(`schema.sql`)
- **보안 미들웨어** — helmet, cors, mysql2 커넥션 풀

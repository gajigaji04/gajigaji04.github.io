## Overview

Windows 디스크에서 무엇이 공간을 차지하는지 빠르게 찾고, `node_modules` · npm · pip · Gradle 캐시 같은 **개발 환경 찌꺼기를 안전하게 정리**하는 도구입니다.
외부 라이브러리 없이 **C11 과 Win32 API 만으로** 작성했고, 명령줄 도구(`disk-scanner`)와 GUI(`bytesieve-gui`)가 같은 Core 를 공유합니다.

최신 릴리스는 [v1.0.1](https://github.com/gajigaji-dev/ByteSieve/releases/tag/v1.0.1)(2026-11-14)이며, 설치 프로그램 · 포터블 zip · SHA-256 체크섬 파일을 함께 배포합니다. 지원 환경은 Windows 10 / 11 x64 입니다.

## 주요 기능

- **폴더 스캔과 트리맵** — 폴더별 용량을 트리 · 목록 · squarified 트리맵으로 표시
- **실제 확보 용량 계산** — 할당 크기 · 하드 링크 수 · 압축 크기를 반영해 "지우면 실제로 비는 용량"을 계산하고, 클라우드 파일은 내려받지 않고 읽음
- **안전한 정리** — 영구 삭제 대신 휴지통 이동(실행 취소 가능) 또는 격리 폴더 이동 · 복원 지원. CLI 의 `clean` 은 기본값이 `--dry-run`
- **Git 프로젝트 분석** — 프로젝트별 미커밋 변경 · 푸시하지 않은 커밋을 읽기 전용으로 확인해 정리 판단을 도움
- **그 밖의 도구** — 드라이브 · BitLocker 상태, CPU · RAM 모니터, CSV · HTML 내보내기, WSL · Docker 가상 디스크 탐지
- **v1.0.1 변경점** — GUI 4개 언어(한국어 · 영어 · 일본어 · 중국어 간체) 즉시 전환, Per-Monitor DPI V2, 직전 기록 비교 속도 개선(150–195ms → 50–56ms), 비교 · 저장 작업을 작업 스레드로 이동

## Technical Details

- **병렬 미리 열거 스레드 풀** — `SRWLOCK` 과 조건 변수로 동기화하고, 최소 힙 큐에 상한을 두어 한도가 차면 가장 늦게 필요한 작업을 내보냅니다. 최대 사용량은 `InterlockedAdd64` · CAS 로 집계합니다.
- **파일 열거** — `GetFileInformationByHandleEx` 의 `FileIdExtdDirectoryInfo`(128비트 ID)를 우선 쓰고, 지원하지 않는 볼륨에서는 `FileIdBothDirectoryInfo` 로 내려갑니다.
- **스캔 작업 분리** — 스캔은 별도 스레드에서 돌고, 진행률 스냅숏은 `CRITICAL_SECTION` 으로 보호하며 취소는 Interlocked 플래그로 처리합니다.
- **휴지통 이동** — Shell `IFileOperation` 에 `FOFX_RECYCLEONDELETE | FOF_ALLOWUNDO` 를 지정해 되돌릴 수 있게 옮깁니다.
- **순수 Win32 GUI** — comctl32 TreeView · ListView 와 GDI 로 그리고, DWM 속성과 `SetWindowTheme` 으로 다크 모드를, `WM_DPICHANGED` 로 고배율 모니터를 처리합니다.
- **테스트 · 배포 자동화** — CTest 테스트 73개(`add_test`), CI 에서 Release 빌드 후 테스트 실행. `v*` 태그를 올리면 패키징 → 설치 프로그램 테스트 → draft 릴리스까지 GitHub Actions 로 처리합니다.

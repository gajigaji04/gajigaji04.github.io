안녕하세요. 백엔드 개발자 김지혜입니다.

Java 와 Spring Boot 를 중심으로 서비스를 설계하고 구현합니다. 기능이 동작하는 것에서 멈추지 않고, 데이터 정합성과 안정성까지 함께 고민합니다. 프로젝트를 하면서 가장 관심을 가져 온 것은 단순히 API 를 만드는 일보다 **예외적인 상황에서도 서비스가 올바르게 동작하게 만드는 일**입니다.

## 개발 경험

- **[Logistics MSA](/projects/logistics-msa/)** — 물류 MSA 팀 프로젝트에서 API Gateway 와 회원 인증 · 인가를 맡았습니다.
- **[TravelPay](/projects/travelpay/)** — 지갑 플랫폼 팀 프로젝트에서 송금 백엔드를 맡았습니다.
- **[Spring Delivery Mini](/projects/spring-delivery-mini/)** — 개인 프로젝트로 주문부터 결제, 정산까지 이어지는 배달 서비스를 만들었습니다.

이 프로젝트들에서 주로 다룬 문제는 다음과 같습니다.

- **데이터 정합성** — 멱등성 키와 DB 제약 조건으로 중복 요청 방지
- **동시성 제어** — 트랜잭션과 잠금 전략으로 데이터 경합 처리
- **장애 대응** — 타임아웃 · 응답 유실 상황에서 결과 확인과 복구
- **성능 개선** — 쿼리 최적화, 캐싱, 부하 테스트로 병목 분석

## 기술을 고르고 검증하는 방식

주로 Java, Spring Boot, Spring Data JPA, PostgreSQL, Redis, Kafka 를 씁니다. 만든 기능은 Docker, Testcontainers, k6, Prometheus, Grafana 등으로 검증하고 성능과 안정성을 확인해 왔습니다.

새로운 기술을 쓰는 것 자체보다, 풀려는 문제에 맞는 기술을 고르고 그 선택을 테스트와 측정 결과로 확인하는 과정을 중요하게 생각합니다.

## 이 포트폴리오를 읽는 방법

[Projects](/projects/) 에는 프로젝트마다 담당 역할, 주요 구현, 기술적 의사결정, 트러블슈팅과 검증 결과를 정리했습니다. 코드와 결과뿐 아니라 어떤 문제를 발견했는지, 왜 그 방법을 골랐는지, 어떤 한계가 남았는지도 함께 보실 수 있습니다.

앞으로도 실제 문제를 이해하고 신뢰할 수 있는 서비스를 만드는 백엔드 개발자로 성장하겠습니다. 읽어 주셔서 감사합니다.
